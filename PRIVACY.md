# Repo Craft privacy policy

## Scope

This policy covers the reviewed Repo Craft plugin package version 1.0.0. It does not describe other versions or tools. Publication of this policy does not by itself announce a software release.

The bundled probe reads the selected local repository and prints a report that the user or coding host can save locally. The terminal renderer reads an explicitly supplied transcript and writes an SVG. Neither script sends network requests, collects telemetry, or requires an account. An optional installed Gitleaks subprocess scans locally and uses redacted output; its availability and failures remain visible.

The coding host can independently send prompt content, repository context and tool results to its configured model provider. Its privacy terms and controls apply separately. Browsing sources or running a repository first-use command can involve network access; review the command and scope before executing it. Use disposable synthetic inputs when real data is unnecessary.

Reports, screenshots and transcripts can contain repository data. Review them before sharing. This package does not supply a hosted service, synchronize files, or publish policies.

## Publisher and contact

Request deletion through that address; provider backups or applicable mandatory retention may outlast live-mailbox deletion.

## Retention and deletion

Repo Craft supplies no hosted storage and has no automatic retention or deletion schedule. Local reports, captures, transcripts, SVGs and edits remain in the locations chosen by the user or coding host until the user removes them. Delete unwanted output files and any copies in Git history, backups or shared destinations using those systems’ controls. Deleting local files does not delete copies previously sent to a model provider or another service; use that provider’s privacy controls or deletion process. Review artifacts for private repository content before sharing them.
