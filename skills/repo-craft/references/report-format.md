# Report format

Lead with the changed result and limits. Scale to the project; do not fill empty phase headings.

For presentation changes include retained before/after paths, first-use execution, asset provenance and regeneration steps, rendered widths/themes and screenshots, local-preview versus host scope, resolved visual defects and unverified behavior. A source diff is not render evidence. Report keep/skip decisions with project-specific reasons, not a generic polish score.

```md
# Repo Craft: project name

The README now explains the current task and links a reproducible result.
Publication is pending; no external operation was included in this request.

## Findings
- Evidence: safe observation, repository-relative location and scope.
- Signal: detector interpretation still needing inspection.
- Resolution: confirming/refuting evidence, including no-change resolutions.
- Taste: proposed design choice and reader benefit.
- Decision: action taken, deliberate omission or pending check.

## Artifact decisions
| Artifact | Keep/skip | Reason |
| --- | --- | --- |
| Terminal result | Keep | It demonstrates the planner respecting a named limit. |
| Trailer | Skip | The complete result is readable in one still. |
| Pages | Skip | No separate navigation or interaction is needed. |

## Verification
Actual commands, observed results, relevant environment and remaining limits.
Name separate history and working-tree scanner states.
Link the safe probe report and reproducible example when available.

## Changed files
Repository-relative paths and focused commit(s).

## External operations
Exact destination and action, authorization present or needed, prerequisites,
and observed result if performed.

## Chosen exceptions
A user preference differing from the recommendation, and its reason.
```

Exclude private absolute paths, secrets and raw scanner output. Preserve safe counts and status without reproducing findings.

Call a condition blocking only when its consequence blocks a particular requested action. Missing optional artifacts do not block local completion. An unresolved check is unverified, not proof that the repository fails it.

Keep observation, interpretation and taste distinct. A verified false positive can close without an edit. Do not claim every scope clean because the script returned 0. Report rendering, installation or publication complete only after it happened.

A few consequential decisions are enough. Avoid scores, document quotas, exhaustive catalogues and readiness percentages.
